# Quantum extras, on top of requirements.txt.
#
# Install torchquantum from GitHub, not PyPI, and always WITHOUT its dependency
# list. The last PyPI release (0.1.8) imports qiskit.providers.aer, a path
# removed in qiskit 1.0, so it cannot run against a current qiskit. GitHub main
# (0.3.0) uses qiskit_aer and works with qiskit 2.x. The declared dependencies
# pull in tensorflow, pyscf and qiskit<1.0.0, none of which statevector
# simulation uses, and pyscf has no Windows wheels.
#
#   pip install --no-deps git+https://github.com/mit-han-lab/torchquantum.git
#   pip install -r requirements-quantum.txt
#
# On Kaggle install these but never the pinned torch from requirements.txt.
# See quantum/README.md, and verify with: python -m quantum.smoke_test
